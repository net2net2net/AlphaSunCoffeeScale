## 3. 核心计算公式（生成配方 ComputeRecipe）

```
dose    = Clamp(dose, 5, 60)
ratio   = Clamp(ratio, 8, 20)
size    = dose≤12 ? small : dose≤22 ? standard : large     // 未显式指定时
restDays= Clamp(显式值或 (Today−烘焙日).Days, 0, 120)        // 烘焙日期优先
roastAg = 显式值 ?? (AgMin+AgMax)/2                          // 默认档位中值

ratioEff   = Clamp(ratio + Process.RatioAdj, 8, 20)          // 处理法微调粉水比
totalWater = Round1(dose × ratioEff)                          // 计划总水量 g

rf        = RestFactor(restDays)                              // 养豆排气系数（见表 4.1）
bloomWait = int Clamp(Round( Roast.BloomBase × rf × Flavor.BloomMul × Process.BloomMul × grindBloomMul ), 10, 75)
temp      = int Clamp( Roast.Temp + Flavor.TempAdj + Process.TempAdj + grindTempAdj, 80, 96 )
flow      = Clamp( Dripper.FlowBase + Grind.FlowAdj + Filter.FlowAdj, 3, 14 )     // 建议流速 g/s

grindBloomMul / grindTempAdj：仅当研磨度为「用户显式覆盖」时取档位值，否则取 1.0 / 0.0
  —— 推荐研磨度本由烘焙度推导，若再叠 TempAdj/BloomMul 会与烘焙度修正重复（刻意设计）。

needRinse = Filter.Rinse                                   // 原色/剑麻/金属/绒布 → UI 提示先润湿
```

> 2026-09-08 起**移除海拔/沸点封顶**：水温只由 烘焙度×风味×处理法(×显式研磨) 决定，不再有海拔补偿。

## 4. 分段修正系数

### 4.1 养豆排气系数 RestFactor(天)

| 养豆天数 | ≤1 | 2–3 | 4–7 | 8–14（理想窗口） | 15–21 | 22–30 | >30 |
|---|---|---|---|---|---|---|---|
| rf | 1.8 | 1.5 | 1.2 | 1.0 | 0.85 | 0.7 | 0.55 |

### 4.2 养豆状态推荐 RecommendRest(roast, days)

| 条件 | 状态 | 说明 |
|---|---|---|
| days < lo | 偏新鲜 | 提示还需等 (lo−days) 天，理想窗口 lo–hi |
| lo ≤ days ≤ hi | 最佳赏味窗口 | 状态文案 |
| hi < days ≤ hi+14 | 风味渐退 | — |
| days > hi+14 | 已过赏味期 | — |

养豆期满日期：最早可赏味 `烘焙日+IdealMin`，完全养豆 `烘焙日+IdealMax`（UI 只读展示）。

### 4.3 推荐研磨度 RecommendGrind(dripper, roast, density)

```
基准档（滤杯）：wave→medium_coarse；smart→coarse（现含 switch/gina 由调用方决定）；
                其余（v60 等）→ medium_coarse
烘焙修正：blonde/super_light/ultra_light/light/medium_light → +1（更细）
          medium_dark/dark/ultra_dark/extreme_dark        → −1（更粗）
密度修正：dense → +1（致密硬豆磨细一档）；light → −1（疏松豆磨粗一档）
idx = Clamp(基准+烘焙+密度, 0, 4)；GrindOrder = coarse<medium_coarse<medium<medium_fine<fine
```

## 5. 阶段路线图（Phase 序列）

阶段两类：**Pour 注水**（按重量达标推进，`累计重量 ≥ Target−0.4` 即进入下一阶段）、
**Wait 等待/滴滤**（按时间达标推进）。各方法模板：

| 方法/分支 | 序列规则 |
|---|---|
| Classic 经典分段 | 闷蒸注水(粉量×BloomMul) → 闷蒸等待(bloomWait) → N=Segments 段注水，第 i 段目标 `bloom+余量×i/N`，段间等待 SegGap → 滴滤 DrawWait |
| oneshot/osl/rao 单次大流量 | 闷蒸注水 → 闷蒸等待 → 一次注至总量 → 滴滤 DrawWait |
| kasuya46 | 5 段等水量（每段总量×20%），前 2 段后等待 `Clamp(Round(K46First×rf×Flavor.BloomMul),10,75)`，后 2 段 `Clamp(Round(K46Late×rf),10,60)` → 收尾 |
| light 浅烘加强 | 闷蒸注水(粉量×(BloomMul+1)) → 等待 → 注至 55% → 等待 → 注至 85% → 等待 → 注至总量 → 滴滤 |
| reverse 逆向 | 同 Classic 段序（中心细流、由外向内，段序提示不同） |
| swiss 瑞士搅拌 | 闷蒸 → 闷蒸等待 → 搅拌 8s → 每段注水后搅拌 10s（段数=max(2, Segments−1)）→ 滴滤 |
| Immersion 聪明杯系（switch/gina/smart 滤杯） | 闷蒸注水 → 闷蒸等待 → 注至总量×50% → 注至总量 → 浸泡 `Clamp(Round(120×rf),90,200)` → 开阀滴滤 DrawWait |
| Cupping 杯测 | 注水浸润引导(30s) → 闷蒸等待 → 破壳 20s → 浸泡 `Clamp(Round(540×rf),420,660)`；**全程按时间推进，不依赖注水模拟** |

- 预计总时长 `TotalTimeSec = Σ各阶段Duration + Σ(每段注水量 ÷ 建议流速)`（Pour 按重量推进，需折算注水耗时）。
- 完成判断/强制跳转：`NextPhase/PrevPhase` 支持手动前进/回退（首段回退=重计本段）。
- 快照：阶段进度 Pour=`Clamp((重量−段始重)/(目标−段始重),0,1)`；Wait=`时间/时长`；
  整体进度=`重量/TotalWater`；实际粉水比=`重量/dose`。

## 6. 黄金杯萃取模型（诊断＋自动校准）

基准（累加式）：水温 92℃、研磨基准 C40=24、基准 EY 19.5%、基准段数 4、吸水系数 2.0 g/g。

```
EY%  = 19.5 + Δ烘焙 + Δ处理 + (24 − C40)×0.30 + (水温−92)×0.18 + (段数−4)×0.20 + Δ水质 + Δ养豆
TDS% = EY ÷ (ratio − 2.0)                      // 粉水比反推核心
黄金杯 ⇔ EY∈[18,22] 且 TDS∈[1.15,1.45]          // SCA 黄金杯判据
```

| 修正源 | 取值 |
|---|---|
| Δ烘焙 | blonde/super_light/ultra_light −1.0；light/medium_light −0.5；medium 0；medium_dark +0.7；dark/ultra_dark/extreme_dark +1.5 |
| Δ处理 | washed/k72 −0.2；honey 0；natural +0.3；wet_hulled +0.2；carbonic +0.4；anaerobic/barrel +0.6 |
| Δ水质 | 推荐水质 GHmax<40 → −0.8；GHmin>100 → +0.3；否则 0 |
| Δ养豆 | 0–4 天 −0.5；>45 天 +0.3；否则 0 |
| 目标 TDS | 醇厚 1.44 / 均衡 1.36 / 明亮 1.28（供诊断建议参考） |

**自动校准（生成方案必须落入黄金杯，2026-09-03 需求；杯测法不参与）**：
- EY 出界 → **研磨微调**（仅限引擎推荐研磨，不覆盖用户显式研磨；同向最多 2 档，0.30%/档）：
  EY<18 往细调，EY>22 往粗调；
- TDS 出界 → **粉水比步进校准**：上界以 TDS≤1.44、下界以 TDS≥1.16 取最近的 0.1 步值（clamp 8–20）；
- 任一变动 → 按最终参数**重建阶段序列并复算诊断**；结果写入 `GoldenCupTune` 说明文案（如「研磨 中→中细；粉水比 15→15.2」）。

## 7. 实时状态机与警告

- 注水偏快：`Flow > max(10, 建议流速×1.7)` → 提示目标区间 `建议流速–建议流速×1.4 g/s`；
- 注水停滞：`Flow<0.4 g/s 且进入本段>1.5s` → 提示保持水流；
- 杯测法：静态计时模式，UI 隐藏注水模拟（IsCupping）。

## 9. 公式速查表（给新手模式/简易计算器复用）

| 目标 | 公式 |
|---|---|
| 总水量 | 粉量 × 粉水比（处理法微调后） |
| 建议流速 | 滤杯基准 + 研磨修正 + 滤纸修正（3–14 g/s） |
| 闷蒸时长 | 烘焙基准 × 养豆系数 × 风味 × 处理法（×显式研磨），10–75s |
| 推荐水温 | 烘焙基准 + 风味 + 处理法（×显式研磨），80–96℃ |
| 研磨度 | 滤杯基准 → 烘焙 ±1 档 → 密度 ±1 档 |
| 养豆期满 | 烘焙日 + 该档理想养豆区间（最早/完全） |
| 黄金杯 | EY=19.5+ΣΔ+…；TDS=EY/(粉水比−2)；EY 18–22 且 TDS 1.15–1.45 |
