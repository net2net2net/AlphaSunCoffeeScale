# 04 · 冲煮参数总表

> 参与手冲咖啡计算逻辑的**全部参数**一览。口径来源：`CoffeeScale.Core/BrewEngine.cs`（引擎标定）+ `Models.cs`（RecipeOptions 入参）+ `Settings.cs`（持久化）+ `ParamInfo.cs`（知识库）。
> 更新：2026-09-14 · 对应版本 v1.5

---

## 一、一句话总览

**13 个用户可选输入（含 2 个日期）→ 引擎推导出 1 套配方（含 10 类推荐值 + 分段步骤 + 黄金杯诊断）。**

```
输入(15) ──► BrewEngine.ComputeRecipe ──► Recipe ──► 阶段序列 + 黄金杯校准
```

---

## 二、用户输入参数（13 个选项 + 2 个日期）

| # | 代码键 | 名称 | 类型 / 取值 | 默认 | 引擎中的作用 |
|---|---|---|---|---|---|
| 1 | `Method` | 冲煮方式 | 枚举 10 种 | `classic` 经典分段法 | 决定**阶段序列生成器**（分段节奏 = 萃取曲线） |
| 2 | `Dose` | 粉量 | 数值 5–60 g | 15 g | 产量基数：总注水 = 粉量 × 粉水比 |
| 3 | `Ratio` | 粉水比 | 数值 8–20 | 15 | 决定总注水量；受处理法 RatioAdj 修正 |
| 4 | `Roast` | 烘焙度 | 枚举 **10 级**（Ag 20–120） | `light` 浅烘 | **第一驱动量**：定水温、闷蒸、养豆窗口、研磨倾向 |
| 5 | `RoastAg` | 烘焙值 Ag | 整数 10–120（粉样标尺） | 档位中值 | 档位内的精确落点；驱动档位归属 |
| 6 | `Flavor` | 风味目标 | 枚举 3 种 | `balanced` 平衡 | 修正水温 ±1℃、闷蒸 ×0.9/1.0/1.2 |
| 7 | `Process` | 处理方式 | 枚举 8 种 | `washed` 水洗 | 修正闷蒸(×)、水温(±℃)、粉水比(±) |
| 8 | `Dripper` | 滤杯 | 枚举 8 种 | `v60` | 基准流速、研磨基准、是否浸泡式 |
| 9 | `Filter` | 滤纸 / 滤网 | 枚举 6 种 | `bleached` 漂白 | 流速修正(±g/s)、是否需润洗 |
| 10 | `Origin` | 产地 | 枚举 19 个 | `ethiopia` | **仅风味参考**（区域/风味谱/等级），不修正数值 |
| 11 | `Variety` | 豆种（品种） | 枚举 14 个 | `heirloom` | 物种/密度背景，不单独改大框架 |
| 12 | `Density` | 咖啡豆密度 | 枚举 3 种 | `medium` 中等 | **研磨 ±1 档**（致密更细 / 疏松更粗） |
| 13 | `BeanAltitudeM` | 咖啡豆海拔 | 整数 0–3000 m | 1500 m | **密度便捷预填**（不直接进水温水） |
| 14 | `RestDays` | 养豆天数 | 整数 0–120 | 10 天 | 排气系数 rf → 闷蒸倍率 |
| 15 | `RoastDate` | 烘焙日期 | 日期 | 空 | 优先用于推算养豆天数 + 养豆期满日 |
| — | `Size` | 粉量档位 | 枚举 3 种 | 自动推断 | 决定分段结构（段数/间隔/收尾） |
| — | `Grind` | 研磨度 | 枚举 5 档 | 引擎推荐 | **非用户项**，仅供测试/高级显式覆盖 |

> 说明：
> - `Size` 默认由粉量自动推断（≤12g 小 / 13–22g 标准 / ≥23g 大），也可手动指定。
> - `Grind` 默认由「滤杯 + 烘焙度 + 密度」推荐，用户不选；显式传入时才参与（并触发 BloomMul/TempAdj 生效）。

## 三、引擎推导输出（配方 Recipe）

| 类别 | 字段 | 说明 |
|---|---|---|
| 基础 | `Dose` / `Ratio` | 有效粉量、有效粉水比（已含处理法修正 + 黄金杯校准） |
| 水量 | `TotalWater` | 总注水量 = 粉量 × 有效粉水比 |
| 时间 | `TotalTimeSec` | 总时长 = 各阶段等待秒数 + Σ(注水量 ÷ 推荐流速) |
| 水温 | `Temp` | 80–96℃ 钳制；杯测法固定 94℃ |
| 闷蒸 | `BloomWait` | 10–75s 钳制 |
| 研磨 | `Grind` / `GrindC40` / `GrindEK` | 档位 + C40 / EK43 对照刻度 |
| 流速 | `RecommendedFlow` | 3–14 g/s 钳制 |
| 水质 | `Water` / `WaterNote` | 4 档（软水/均衡/低矿/极软），含 TDS·GH·KH 建议 |
| 养豆 | `RestRec` / `RestReadyMinDate` / `RestReadyMaxDate` | 状态判定 + 最早/完全养豆日期 |
| 润洗 | `NeedRinse` | 是否需润湿滤纸 |
| 分段 | `Phases[]` | 阶段序列（Pour 按重量推进 / Wait 按时间推进） |
| 诊断 | `Extraction`（EY / TDS / 是否黄金杯）/ `GoldenCupTune` | 黄金杯估算 + 自动校准说明 |
| 信息卡 | `Origin*` / `Variety*` | 产地风味谱、等级、大区（展示用） |

## 四、参数修正链（引擎内部规则速查）

### 4.1 水温
```
Temp = Roast.Temp + Flavor.TempAdj + Process.TempAdj + Grind.TempAdj（显式覆盖时）
     → Clamp(80, 96)；杯测法固定 94℃
```
> 海拔**不参与**水温（沸点封顶逻辑已于 2026-09-08 移除）。

### 4.2 闷蒸秒数
```
BloomWait = Roast.BloomBase × rf(养豆) × Flavor.BloomMul × Process.BloomMul × Grind.BloomMul
          → Clamp(10, 75)
```
排气系数 rf：≤1天 ×1.8 / ≤3天 ×1.5 / ≤7天 ×1.2 / ≤14天 ×1.0 / ≤21天 ×0.85 / ≤30天 ×0.7 / >30天 ×0.55

### 4.3 粉水比（有效）
```
RatioEff = Clamp(Ratio + Process.RatioAdj, 8, 20)  →（黄金杯校准可能再微调 0.1 步）
```

### 4.4 研磨
```
Grind = GrindOrder[ Clamp(滤杯基准档 + 烘焙度修正 + 密度修正, 0, 4) ]
  滤杯基准：v60/其他 → medium_coarse；wave → medium_coarse；smart → coarse
  烘焙度：浅烘系 +1（更细）/ 深烘系 −1（更粗）/ 中间 0
  密度：dense +1 / light −1 / medium 0
```
档序（粗→细）：`coarse → medium_coarse → medium → medium_fine → fine`

### 4.5 推荐流速
```
RecommendedFlow = Clamp(滤杯 FlowBase + 研磨 FlowAdj + 滤纸 FlowAdj, 3, 14)  // g/s
```

### 4.6 海拔 → 密度（预填）
```
≥1700m → dense 致密 ｜ 1200–1699m → medium 中等 ｜ <1200m → light 疏松
```
语义：改海拔刷新密度；在密度下拉框手选一次后（`_densityUserSet=true`）不再被海拔回写。

### 4.7 黄金杯萃取诊断
```
EY  = 19.5 + Δ烘焙 + Δ处理 + (24 − C40)×0.30 + (T − 92)×0.18 + (段数 − 4)×0.20 + Δ水质 + Δ养豆
TDS = EY ÷ (ratio − 2.0)
黄金杯判据：EY ∈ [18, 22]%  且  TDS ∈ [1.15, 1.45]%
```
Δ烘焙（浅 −1.0 / 中浅 −0.5 / 中 0 / 中深 +0.7 / 深 +1.5）
Δ处理（水洗 −0.2 / 蜜 0 / 日晒 +0.3 / 厌氧 +0.6 / 湿刨 +0.2；碳酸 +0.4 / 酒桶 +0.6）
Δ水质（GH<40 −0.8 / GH>100 +0.3）；Δ养豆（0–4天 −0.5 / >45天 +0.3）
→ 出界时引擎自动调研磨（≤2 格）与粉水比，使推荐方案落入黄金杯（杯测法不参与校准）。
